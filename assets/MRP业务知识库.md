# MRP 业务知识库（Phase 2）

## 业务目标

商务维护整机月经营计划，仓库提供全层级库存，系统使用冻结 BOM 和业务策略逐层计算净需求，计划人员最终维护日排产。系统自动处理确定性计算，所有需要业务判断的事项先进入工作台。

## 角色

| 角色 | 主要职责 |
|---|---|
| 商务 | 导入整机经营计划，确认版本 |
| 仓库 | 导入库存快照，维护仓库/可用量口径 |
| 物料管理 | 维护分类角色、物料供应/下钻策略、BOM 异常 |
| 计划员 | 维护生产日历、处理决策/库存分配、调整和发布日排产 |
| 管理/只读 | 查看批次、周/月汇总、版本和追溯 |
| 管理员 | 权限、工厂数据域和系统配置 |

## 业务对象

- 来源整机：经营计划根料号；
- 当前物料：多层展开中正在扣库存的节点；
- 末级需求物料：结构叶子或 STOP 节点，可能是机头、PCBA、原材料或其他物料；
- 库存池：同一快照、仓库、物料和品质的库存；工厂通过已发布一对一映射使用指定仓库；
- 业务决策：对缺配置、缺库存、共享库存、BOM 异常和非生产日落点的确认；
- 日排产：最终排产日期上的唯一事实；
- 周/月汇总：日事实的只读统计。

## 核心数据流

```text
整机月经营计划
  -> 冻结输入版本
  -> BOM/主数据/库存/日历预检
  -> 分析波次（发现深层问题和共享库存需求）
  -> 业务决策与共享库存分配
  -> 重新分析直至稳定
  -> 逐层毛需求、库存使用、净需求
  -> 末级月需求
  -> 来源月有效生产日分配
  -> 整体提前7自然日
  -> 非生产日待分配
  -> 日排产事实
  -> 周/月只读汇总
  -> 调整、校验、发布
```

## 关键认识

- 分类角色不是下钻策略；外购/委外不是天然终点；
- 没有库存记录与库存为0含义不同；
- 同一仓库库存在多个整机、月份、路径之间共享，不能重复扣；跨仓库不合并；
- 共享库存先保较早来源月，同月内按经营计划已冻结顺序分配；
- 安全库存是不可自动消耗的保底，预警库存只用于风险提示；
- BOM 数量必须按子项数量/父项基准数量计算；
- 日计划解决四周/五周、跨月和节假日问题；周标签由业务发布 W1-Wn 日期范围后聚合；
- 主页面只显示最终排产日期，来源日期留在追溯；
- 已出货本期是 TODO，不影响计算；
- Phase 1 周模型保留历史读取，不作为 Phase 2 设计基础。
- Phase 2 计算批次是唯一计划身份；结果先写隔离 run，校验通过后才切换可见指针。

## 页面阅读

日排产固定展示来源整机、末级需求物料、终点/供应、工厂和日期列。日期按已发布业务周 W1-Wn 分组，每周合计只读。详情查看仓库、库存优先级、安全/预警库存、来源月份、来源日期、BOM 路径、逐层库存扣减和调整历史。
