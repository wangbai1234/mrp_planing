- W11 (10月第3周): 334 (10月剩余)

**实际结果**（2026-09-16）：
- W1 (8月第1周): 300 (8月) ✓
- W2 (8月第2周): 300 (8月) ✓
- W3 (8月第3周): 300 (8月) ✓
- W4 (8月第4周): 400 (9月W1 carry) ✓
- W5 (9月第1周): 0 (9月W1已carry到8月W4) ✓
- W6 (9月第2周): 400 (9月W2) ✓
