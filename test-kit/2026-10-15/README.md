# MRP 测试交接包

先读《交接执行Prompt.md》，再读《测试手册.md》《执行结果.md》《已知问题.md》。`用例清单.csv` 是 119 项待执行记录模板，保持 NOT_RUN；本次已有结果单独记录，接手者不要批量改成 PASS。

包含 29 份可导入 Excel、真实主数据只读提取、计算配置、Python Decimal 独立预期、API/E2E/监测及保护校验脚本。`data/dataset-manifest.json` 为当前数据规模真源。十万行仅提供 CSV/JSON 源数据，XLSX 生成工具 OOM；应用十万行导入尚未执行。

全部业务写入隔离环境：前端 5181、后端 8180、MySQL 3317、Redis 6391。原物料、分类和 BOM 不进行管理功能测试，不修改。主库不得清空。已有本包环境请复用，禁止重建 volume 隐藏失败现场。

已验证后端 328 项、前端 61 项、数据包 4 项、基础浏览器冒烟 16 项通过；大批次另有 1 项浏览器验证。1,411 整机六个月产生 224,100 日事实，独立 SQL 和批量 HTTP 数量/维度全量比对均无差异；仍有两个 P1 应用缺陷，以及大批次页面/分页性能问题。**整体系统尚未通过完整验收。**

分享使用本目录外生成的 `MRP测试交接包-2026-10-15.zip`。不包含 `.env`、运行目录、原始 Playwright trace/HTML 报告及凭据。ZIP 含内部业务料号和 BOM 输入，仅交给有权限的测试者。脚本依赖本仓库的应用代码和既有依赖，ZIP 不是独立应用安装包。
