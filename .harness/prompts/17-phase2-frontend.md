# 阶段 17：Phase 2 前端与原型

## 目标

实现配置、决策、库存分配和日排产页面，以及周/月只读汇总。

## 必读

`prototype/` 对应新旧原型、`assets/import-design-rules.md`、`.harness/list-rules.md`、`.harness/api-contract.md`、v4.0 第 10 节、完整开发手册第 8 节。

## 执行

1. 先创建并评审固定文件 `prototype/MRP日排产Phase2可交互原型.html`；原型只作为 UI 契约，不复制 vanilla JS。若原型不存在，不得跳过该门禁。
2. 使用 Vue 3 + TypeScript + Element Plus + fetch，不引入未批准状态库，不使用 any 绕过类型。
3. 顶层计划入口固定为单一 `MRP 工作台`，不再提供独立批次列表页；工作台默认加载当前版本并优先展示日排产，历史版本放在右上角弹窗中选择后切换主视图。决策/库存分配、日/周/月汇总作为同一工作台标签，避免把子视图做成顶层菜单。
4. 日表固定“来源整机、末级需求物料、终点/供应、工厂”；日期按已发布业务周 W1-Wn 分组。
5. 默认28天、可看12周；服务端分页和虚拟滚动；rowKey 驱动详情和编辑。
6. 删除 Phase 2 “拆分维度”入口；停止点来自物料策略。
7. 实现日调整、多日重分配、追溯、库存扣减、空/加载/错误/权限/STALE 状态。
8. 周/月只读，切换不写数据。
9. 增加已执行/已锁定日状态和实际完成量确认；锁定日期不可编辑，执行差异显示异常。
10. 发布后只提供“生成修订版”，不提供直接修改已发布批次；修订批次只允许未来未锁定日。
11. 库存导入/详情/预览展示 `inventory_quality`（GOOD/DEFECTIVE），GOOD 与 DEFECTIVE 不得合并显示为单一可用库存。
12. 修复 Playwright 本机绝对浏览器路径为可移植配置；浏览器缺失按环境规则停止。
13. 新增工厂仓库映射、库存控制策略、业务周期间页；库存快照按仓库卡片展示，分配工作台展示经营计划优先级、安全库存和预警状态。

## 门禁

- npm build/test/typecheck；
- 实际 API 联调和浏览器验证；
- 双来源同末级编辑隔离；
- API/UI 使用 batchId 作为 Phase 2 planId，不引用旧 plan_version_id；
- 1440x900、1920x1080、84日滚动、无重叠/溢出；
- Playwright 强断言覆盖核心闭环、401/403/500/空数据。

完成后 REVIEW，独立 UI/E2E Reviewer PASS 后进入 18。

## C025 双工作台增量

第 3、4 条的单一顶层入口和整机/末级混合主表由 C025 取代。`/planning` 默认只呈现 MACHINE_OUTPUT 整机日排产；`/shortage` 独立呈现末级需求物料、库存风险、决策、分配与追溯。两页共享批次和 run；整机页展示物料状态及跳转，物料页可回到来源整机。先更新可交互原型，再按新原型实施；保持服务端分页、空/加载/错误与权限状态。

## C026 分岗页面修订

C025 的页面互跳和整机页展示物料状态被 C026 覆盖。两页通过批次与复核状态交接，不提供互跳；物控默认角色不持有整机排产访问权限。排产页版本信息只展示输入，生产日历在预检阻断，执行与锁定独立于排产确认。对应页面契约见 `docs/MRP排产与缺料分岗页面裁决-2026-11-02.md`。
