## 状态

- 待业务决策：系统提供工作台，业务确认后计算；

## 已确认范围

| 范围 | 最新基线 |
|---|---|
| 经营计划 | 整机料号+自然月，现有设计保留 |
| 库存 | 覆盖整机、机头、PCBA、原材料及其他 BOM 节点 |
| 库存范围与品质 | 快照按仓库+物料+`inventory_quality` 汇总；GOOD 参与，DEFECTIVE 排除但保留追溯 |
| 工厂仓库 | 已发布一对一映射；初始覆盖永惠、爱培科、惠州仓，工厂不跨仓扣减 |
| BOM | 递归到结构叶子或业务 STOP 节点 |
| BOM版本 | NC 按库存组织+父料号+子料号选择最高有效版本；冲突阻断，计算只读固化快照 |
| 净需求 | 每层先扣当前物料库存，只把净需求传给下层 |
| BOM 比例 | `childQty / parentQty` |
| 末级物料 | 可能是原材料、PCBA、机头或其他 STOP 节点 |
| 分类角色 | 业务版本化维护整机/机头/PCBA/原材料/其他/排除 |
| 物料策略 | 供应方式与 EXPLODE/STOP 分开维护 |
| 缺库存 | 无记录不等于 0，业务确认后才能继续 |
| 共享库存 | 同仓跨整机、月份、路径共享；先来源月，同月按经营计划顺序自动分配，支持人工覆盖 |
| 安全/预警库存 | 按仓库+物料版本化维护；安全库存是硬保底，预警库存作风险提示 |
| 排产事实 | 只保存日排产事实；周按已发布 W1-Wn 日期范围、月按日事实只读聚合 |
| 日分配 | 月净需求按来源月有效生产日权重分配 |
| 提前 | 来源日整体提前 7 个自然日 |
| 非生产日 | 进入待分配池，由业务选择合法生产日 |
| 页面列 | 来源整机、末级需求物料、终点/供应、工厂 |
| 页面日期 | 只展示最终排产日期，不展示来源周/实际周 |
| 数量 | BigDecimal/DECIMAL(18,6)，整数用最大余数法 |
| 单位换算 | MVP 不做换算，按现有数字和 `childQty/parentQty` 计算 |
| 执行与重算 | 已执行/已锁定日不可覆盖；月中只重算未来未锁定日；重算新建 run，差异生成异常 |
| 发布后修改 | 生成修订批次，不原地修改已发布版本 |
| 已出货 | TODO；本期不参与公式、checksum、预检和发布 |

## 决策前置原则

以下情况系统不猜测，预检或分析波次生成问题，业务在工作台处理；系统重新分析至稳定后才锁定决策：

- 分类角色、供应方式或下钻策略未维护；
- 无库存记录；
- 共享库存的人工分配覆盖；
- 外购/委外物料是否继续下钻；
- EXPLODE 但无有效下级 BOM；
- BOM 最高版本重复、有效期重叠或库存组织不明；
- 提前后落在非生产日；
- 来源月份没有有效生产日。

计算开始后不得弹窗等待。输入或配置变化后，未发布批次和相关决策标记 STALE。

## 黄金示例

```text
A计划1000，A库存100
A -> B×1，B库存200
A -> C×2，C库存300
B -> D×1，D库存200
C/D末级

A净900
B毛900、净700
D毛700、净500
C毛1800、净1500
最终 C=1500、D=500
```

## 发布门禁

- 阻断问题为 0；
- 待分配量为 0；
- 所有日期是合法生产日；
- 每层毛需求=库存使用+净需求；
- 子项毛需求=父项净需求×单位用量；
- 来源月日合计=月末级净需求；
- 日合计=周/月汇总；
- 人工调整守恒并有审计；
- 输入 checksum 未变化。

## 待冻结后续口径

以下见 `MRP待确认问题池.md`，不得由开发自行决定：

- 月中重算后的库存分配保留原分配还是重新分配；
- 日产能、产线分配及超限平移；
- 损耗率、良率、替代料和在途库存是否进入公式。
