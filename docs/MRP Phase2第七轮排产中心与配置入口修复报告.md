# MRP Phase 2 第七轮排产中心与配置入口修复报告

> 验收日期：2026-09-29

## 1. 本轮修复结论

1. `/mrp/batches` 已从“所有批次均需操作”重构为“唯一当前排产 + 历史版本只读查询”。
2. 物料策略、生产日历已增加独立菜单与维护页面，支持草稿、明细保存和发布。
3. 新建排产的工厂仅能从启用的产能配置中选择；生产日历按工厂过滤。
4. 经营计划接口已按分页契约取 `items`，不再显示 `Vundefined`。
5. 新建排产不再允许选择历史 BOM 快照，系统自动锁定最新 `READY` 快照。
6. 库存导入模板和页面已使用“良品/不良品”；导入解析同时兼容旧值 `GOOD/DEFECTIVE`，数据库仍保存标准内部码。

## 2. 后端业务门禁

创建 MRP 排产时已校验：

- 经营计划必须存在且为已导入状态。
- 库存快照必须存在且为已导入状态。
- BOM 快照必须为 `READY`。
- 物料分类角色、物料策略、生产日历必须已发布。
- 生产日历的工厂必须与排产工厂一致。

“当前排产”的后端查询仅会选择引用全部有效、已发布输入的最新非终止批次，历史测试草稿不会再抢占当前排产。
