# MRP Phase 2 UAT 验收案例库

> Phase 1 的历史实测结果保存在 00-09 阶段报告。本文件只验收 v4.0。当前案例均为待执行，禁止在没有运行证据时标记通过。

状态：待测试 / 进行中 / 已通过 / 失败 / 阻塞。

## 一、多层净需求

### P2-TC001 黄金链路

输入：A计划1000、A库存100；A->B×1/B库存200；A->C×2/C库存300；B->D×1/D库存200；C/D末级。
预期：A净900，B净700，D净500，C净1500；末级 C=1500、D=500；每层毛=库存使用+净。
状态：待测试。

### P2-TC002 父项基准数量

输入：父项数量2、子项数量3、父净需求10。
预期：子毛需求15，不得按30计算。
状态：待测试。

### P2-TC003 小数与精度

输入：小数经营计划、BOM数量和库存。
预期：全链路 BigDecimal，无 long 截断，结果按物料精度守恒。
状态：待测试。

### P2-TC004 STOP 外购机头

输入：机头供应方式 PURCHASED、策略 STOP，且下层有 BOM。
预期：在机头停止，末级需求物料显示该机头和“机头·外购”，不继续下钻。
状态：待测试。

### P2-TC005 委外 PCBA 与 EXPLODE

输入：PCBA 为 OUTSOURCED+EXPLODE。
预期：继续展开，不因委外自动停止。
状态：待测试。

### P2-TC006 EXPLODE 无 BOM

预期：生成阻断问题；业务可修 BOM 或改 STOP，系统不能静默作为叶子。
状态：待测试。

### P2-TC007 BOM 异常

覆盖循环、父数量0、子数量0或负数、缺物料、多有效 BOM、最大深度/节点，以及根/中间 EXCLUDED。
预期：明确错误码和路径，批次不可计算。
状态：待测试。

### P2-TC007A BOM 版本和库存组织

输入：同一库存组织+父料号+子料号存在多个版本、有效期重叠，以及库存组织为空的数据。
预期：NC 同步只保留唯一最高有效版本；仍重复、重叠或组织不明时生成阻断问题，MRP 不读取未固化数据。
状态：待测试。

## 二、库存与决策

### P2-TC008 缺库存记录

预期：无记录生成 INVENTORY_MISSING；业务确认本批次按0后可继续；确认记录有操作者、原因和 checksum。
状态：待测试。

### P2-TC009 明确零库存

预期：有记录且数量0不生成缺失问题，净需求等于毛需求。
状态：待测试。

### P2-TC009A 良品和不良品

输入：同一快照同一物料分别导入 `GOOD=100` 和 `DEFECTIVE=50`，并增加数量为0的品质记录。
预期：模板、预览、正式快照和规范化余额保留两类品质；MRP 只扣 GOOD=100，不良品不进入可用库存；0记录不生成缺失问题。
状态：待测试。

### P2-TC010 共享库存

输入：两个整机/月份竞争同一物料库存且不足。
预期：进入分配工作台；未确认阻止计算；分配不超 gross/available；两个来源结果分别可追溯。
状态：待测试。

### P2-TC011 分配并发与失效

预期：相同 revision 竞争只有一次成功，另一请求409；经营计划/BOM/库存变化后分配 INVALIDATED。
状态：待测试。

### P2-TC012 主数据未维护

覆盖缺分类角色、供应方式、下钻策略和数量精度。
预期：全部一次预检发现，处理完成前不创建计算任务。
状态：待测试。

### P2-TC012A 经营计划顺序自动分配

覆盖 available=0、单一需求、available 足够覆盖总毛需求以及多来源库存不足。预期：所有场景均按 `source_month + priority_seq + stable key` 生成 `AUTO_PRIORITY`；多来源不足时高优先级先获得库存，低优先级形成净需求。业务仅在显式改变顺序时提交 `MANUAL_OVERRIDE`。
状态：待测试。

## 三、日历与日排产

### P2-TC013 月需求等权日分配

输入：月末级净需求100，20个有效生产日。
预期：每日5，总和100。
状态：待测试。

### P2-TC014 最大余数

输入：整数物料100，3个等权生产日。
预期：按稳定日期顺序34/33/33，总和100。
状态：待测试。

### P2-TC015 非等权与小数

输入：权重1/2/1，小数物料。
预期：按权重分配、按精度回补，月合计严格守恒。
状态：待测试。

### P2-TC016 提前7自然日

覆盖月内、跨月、跨年、闰年。
预期：每条 scheduleDate=sourceDate-7天，不使用“第几周”换算。
状态：待测试。

### P2-TC017 节假日和调休

预期：来源月只在有效生产日分配；调休生产日可分配；普通周末按日历判断而非硬编码。
状态：待测试。

### P2-TC018 提前后非生产日

预期：数量进入待分配，主日事实不伪造落点；业务选合法生产日后归零；未归零不能发布。
状态：待测试。

### P2-TC019 无生产日月份

预期：产生 NO_PRODUCTION_DAY 阻断，不自动跨月。
状态：待测试。

### P2-TC020 五周月与12周尾部

输入：发布的业务周定义包含 W1-W5，W1 和 W5 可跨自然月。
预期：日排产按真实日期计算，周汇总严格按业务发布的 W1-W5 范围聚合；日期无重叠、无空档；展示12周时纳入截止日后7天来源。
状态：待测试。

### P2-TC020B 经营计划优先级与安全库存

输入：共享物料 X 良品库存 150，安全库存 20，预警库存 50；同月整机 A/B 毛需求均为 100，经营计划优先级 A=1、B=2。
预期：A 分配 100，B 分配 30，保留 20，B 净需求 70；显示安全库存风险但不阻止生成需求。
状态：待测试。

### P2-TC020C 工厂仓库隔离

输入：永惠、爱培科、惠州仓同一物料分别有 100/50/200，永惠工厂只映射永惠仓。
预期：永惠工厂只能使用 100，不得读取其他两仓 250。
状态：待测试。

### P2-TC020A 不做单位换算

输入：BOM、经营计划和库存使用可直接比较的数字，单位名称不同但不提供换算表。
预期：系统按数字和 `childQty/parentQty` 计算，不隐式换算、不因单位名称不同阻断；结果可重复。
状态：待测试。

## 四、页面与调整

### P2-TC021 双料号行身份

输入：两个整机产生同一末级物料。
预期：显示两行；来源整机、末级需求物料分别展示；编辑一行不影响另一行。
状态：待测试。

### P2-TC022 多路径详情

输入：同一整机经两条路径到同一末级物料。
预期：主表按冻结规则汇总，详情显示两条路径和各层扣减。
状态：待测试。

### P2-TC023 日调整

预期：系统值保留，人工值生效，周/月即时一致，恢复自动后审计仍在。
状态：待测试。

### P2-TC024 多日重分配

预期：同周一次事务守恒；跨周要求原因；不平衡暂存时禁止发布。
状态：待测试。

### P2-TC025 页面状态

覆盖加载、空数据、401、403、500、STALE、待决策、无日历、并发冲突。
预期：有明确中文反馈，无白屏、控制台或 Network 未处理错误。
状态：待测试。

### P2-TC026 宽表和性能

预期：默认28天，可查看84天；服务端分页；1万行时不全量加载；1440x900和1920x1080无重叠/溢出。
状态：待测试。

### P2-TC026A 已执行/已锁定日保护

输入：业务手动将某天标记 LOCKED 或 EXECUTED，再发起月中重算、日重分配和修订。
预期：该日计划不改变；EXECUTED 必须有实际完成量；实际量与有效计划量不一致生成 `EXECUTION_QUANTITY_MISMATCH`。
状态：待测试。

## 五、任务、发布与兼容

### P2-TC027 确定性和已出货 TODO

预期：相同锁定输入/决策重复计算 checksum 一致；只改变已出货数据，结果与 checksum 不变。

### P2-TC028 Writer 回滚

在批量写中注入失败。
预期：需求、日计划、checksum 和 READY 状态全部回滚，当前发布版本不变。
状态：待测试。

### P2-TC029 幂等、并发和恢复

预期：重复 Idempotency-Key 只建一个任务；双 Worker 仅一个认领；租约过期可恢复；ANALYZING/WAITING_DECISION/REANALYZING 波次可重复；WAITING_DECISION 不被置 FAILED；WRITING 失败 run 不可查询且不留下 READY 半版本。
状态：待测试。

### P2-TC030 发布门禁

逐项制造 issue、待分配、非生产日、守恒差异、STALE。
预期：均阻止发布并返回明细；全部解决后才能发布。
状态：待测试。

### P2-TC030A 发布后修订

输入：发布 V1 后修改未来日期，分别尝试直接改 V1 和创建修订 V2。
预期：V1 直接修改被拒绝；V2 关联 V1、只允许未来未锁定日、重新执行预检/计算/发布，V1 保留可查可对比。
状态：待测试。

### P2-TC030B 月中库存分配未决

输入：月中重算造成原库存分配与新毛需求不一致，未选择“保留原分配/重新分配”。
预期：系统只生成差异预览，受影响批次禁止正式发布，不得自行选择分配方案。
状态：待测试。
