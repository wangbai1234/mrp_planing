# MRP 双工作台产品优化开发方案

**状态：A/B/C 已实现、自测并通过本轮独立修复复核；D 保持 REVIEW，待专用业务批次浏览器写入演练、外部同步核验及整体阶段复核。** 本方案承接 C025 和《MRP双工作台流程与页面精简优化方案-2026-10-29》，适用于排产员与物控共用同一批次、active run 和发布版本的 Phase 2 工作流。

## 目标与不变量

- 排产页默认只维护整机日事实；缺料页默认按工厂、末级物料、终点类型和供应方式汇总，来源月、整机、BOM 路径、仓库分配在详情中追溯。
- 整机确认后物控显式启动分析，物控确认后联合发布。整机调整与库存分配变化按既有指纹和重算规则使旧确认失效。
- 不修改 v5 业务周分配、逐层扣库、历史事实、发布门禁、已应用迁移及权限边界；采购在途和承诺到货仍未接入，页面只称末级净需求和库存风险。

## 实施顺序与门禁

每批先核对原型、需求和真实代码，保持 API 兼容或记录 B 类契约变更。代码修改后依次执行编译、单元测试、真实服务和浏览器/API 验证。需要新字段时只增新 Flyway 迁移。历史版本仅改变只读查询的默认展示粒度，`detail=true` 保留原来源明细；不回写任何结果。未完成的后续批次保持 REVIEW，不能以当前历史 #73 的页面测试代替 v5 全流程验收。
