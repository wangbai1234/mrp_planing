# MRP 测试策略与阶段门禁

## 1. 测试层级

### 规则单元测试

纯 Java 测试覆盖：MAX 公式、库存大于需求、拆分余数、提前量来源月份、跨年月份、月中锁定、人工覆盖和产能异常。测试输入输出，不依赖 Spring。

### 服务集成测试

使用 Spring Boot Test + MySQL 8.x 测试库，验证事务、唯一约束、版本状态和权限过滤。不能把 H2 作为唯一数据库测试。

### Excel 测试

使用项目真实样本和生成模板，覆盖：日期序列 46388、General 格式、2026-12/2027-01、料号文本、空值、重复月份、坏行和大文件流式读取。

### API 测试

验证 HTTP 状态、错误结构、幂等、分页、工厂数据域和长任务 202 响应。

### 前端验收

验证固定 12 周、横向滑动、定位当前周、编辑/恢复自动值、重算、发布、模板下载、导入预览、产能整行编辑和手册纵向滚动。

同时验证 Vue 构建产物由 Spring Boot 静态资源入口正确托管，SPA 路由刷新不返回 404。

## 2. 性能基线

在没有真实生产数据前，使用可复现数据集做基线：

- 10 万整机 × 12 周结果可生成并落库；
- 计算过程无逐料号 N+1 查询；
- 批量写入每批 500–2000 行；
- API 查询首屏不返回全部结果，使用分页或虚拟化；
- 同一输入重复计算结果 checksum 一致；
- 任务失败不会产生 READY 半版本。

具体耗时阈值应在首次压测后记录到 `.harness/decision-log.md`，不得事先编造不可验证数字。

## 3. 阶段门禁

| 阶段 | 必须通过 |
|---|---|
| 发现 | 需求、规则、待确认项和技术栈冲突清单 |
| 后端骨架 | 编译、健康检查、配置分环境、无真实密钥 |
| 数据库 | 空库迁移成功、重复执行幂等、索引存在 |
| 导入 | 三类模板解析、跨年和文本料号测试通过 |
| 计算 | 黄金数据、守恒、可重复性和月中锁定通过 |
| API | 权限、幂等、事务、长任务状态通过 |
| 前端 | 核心页面操作闭环、无控制台错误 |
| 集成 | Docker 从空库启动、前后端联调通过 |
| UAT | UAT 案例库全部有结果，阻断项清零 |

构建门禁还必须确认：后端使用仓库内 Maven Wrapper，前端使用锁定主版本的 Node.js/npm；Docker 镜像不得依赖未声明的 `latest`。若部署环境没有现成 HTTPS 入口，UAT 必须包含反向代理/TLS 方案验证。

## 4. 阻塞规则

以下情况必须停止并报告：业务规则冲突、数据库迁移破坏已有数据、计算结果不可重复、权限绕过、无法识别真实日期、测试环境缺少 MySQL/Docker 且无等价验证。
