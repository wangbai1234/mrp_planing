# Prompt 08：完整测试、性能和数据准确性验收

前置：主链路已联调。

读取 `test-and-gates.md`、UAT、规则库和所有任务报告。执行：

- JUnit 5 规则单元测试；
- MySQL 集成测试和事务回滚测试；
- 真实 Excel、模板、跨年、坏文件和大文件测试；
- API 权限、幂等、分页、202 任务测试；
- 前端浏览器核心流程测试；
- 10 万整机 × 12 周可复现压测；
- N+1 查询、批量写入、Worker 并发和重复 checksum 检查；
- 中断 Worker 后按租约恢复、有限重试和失败版本不污染测试；
- 更新 `traceability-matrix.md`，每条规则填入实际实现和测试证据。

不得编造性能数字。将实际耗时、CPU、内存、SQL 数量和失败率记录到 `.harness/decision-log.md`。未通过项必须修复或标记 BLOCKED，并说明需要谁作出什么决定。通过后状态设为 REVIEW，等待复核。
