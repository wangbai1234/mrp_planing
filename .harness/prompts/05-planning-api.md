# Prompt 05：实现排产领域 API

前置：计算引擎黄金测试通过。

读取 `api-contract.md`、`data-contract.md` 和 UAT。实现 `/api/v1`：

- 当前排产和 12 周网格查询；
- 经营计划/库存导入任务创建、预览、确认和状态查询；
- 重算任务创建和进度查询，返回 202；
- 单元格人工调整、恢复自动值；
- 发布、版本列表和只读比较；
- 产能配置列表、新增、整行编辑；
- 自定义字段导出任务创建和状态查询；
- CRM 同步任务触发。

每个写请求做服务端鉴权、工厂数据域过滤、参数校验、幂等和并发版本检查。错误使用统一结构；列表分页；禁止同步等待长计算；禁止历史版本回滚。写 API 集成测试和权限测试。完成后状态设为 REVIEW，等待复核。
