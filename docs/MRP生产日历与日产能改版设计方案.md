# MRP 生产日历与整机日产能设计方案

日期：2026-10-14。状态：C019 已实施，三层验证及独立复核 PASS。原自制末级口径仅适用于历史 v2 批次，本次不改排产日期规则。

## 1. 需求与业务边界

- 爱培科、永惠分别配置生产日及整机日产能，单位固定为“台/日”。
- 生产日填正整数，停产日为 0；未配置不能当作无限产能。配置页仅维护能力，计划页对本计划冻结的能力评估负荷。
- 工厂当天整机有效计划数量合计超过当天能力时，汇总及参与负荷的整机生产单元格标红，用户跨日调整直至正常。
- 机头、PCBA、原材料等末级数量用于备料计划，不能相加或根据 BOM 用量倒推整机数量。独立周产能入口继续退出当前流程。

## 3. 已验收的计算链路与新口径

现有 DailyCapacityService 按同单位 SELF_MADE 末级日计划加总；仅改“台/日”标签会继续错误预警。NetRequirementEngine 已持久化 levelNo=0 的整机净需求，整机库存扣减发生在 BOM 下钻之前，能作为独立整机计划来源。

整机需生产数量 = 冻结经营计划整机需求 − 按现有库存分配规则扣减的整机库存。数量直接使用根节点 netQty。部件库存、BOM 用量、末级供应方式及 STOP/EXPLODE 影响备料，不影响已经确定的整机净需求。即使备料全部被部件库存覆盖，整机生产计划仍存在；整机库存覆盖全部需求时整机生产量为 0。

新规则 v3-whole-machine-capacity 生成独立 MACHINE_OUTPUT 需求与日事实，单位台，使用现有版本、run、人工覆盖、执行锁和发布链路。该类型表示整机产出，不能与同料号的 STOP 末级需求合并。

## 4. 生产日历页面

保留 /mrp/production-calendars，标题“生产日历”。工厂切换、月份导航、月历/列表、批量新增和导入沿用已落地布局；按用户追加要求移除导出按钮。日产能显示及编辑初始化去除无意义小数尾零，10000.000000显示10000。

月历每天展示日期、生产/停产/未配置和整机日产能。统计为生产天数、月配置产能（台）、未配置天数。列表按服务端筛选分页，默认每页20条。

| 日期 | 状态 | 整机日产能 |
|---|---|---:|
| 10/12 | 生产 | 1,000 台/日 |
| 10/13 | 生产 | 800 台/日 |
| 10/14 | 停产 | 0 台/日 |
| 10/15 | 未配置 | 待维护 |

单日与批量设置均显示“整机日产能（台/日）”，单位固定台；生产日为正整数，停产强制0。批量按日期区间和星期选择，提交前预览保留/覆盖特例。任意多个日期勾选不在本次范围。

旧配置若为件、千克或单位缺失，保留原记录并提示按整机口径重新维护，不自动把数字改名为台。用户编辑确认后才形成新口径配置。导入保留工厂编码、日期、生产日、日产能、单位、备注六列表头，其中“日产能”按整机台数填写，单位仅台，整份预检通过后确认；导出如实保留历史记录单位。

## 5. 分配权重与日期规则

权重仅决定月数量在日期之间的比例，不是能力上限，也不负责两工厂分工。例如权重1、1、2把400分成100、100、200。

新配置继续取消权重，整机按来源月有效生产日等量初排，整数采用最大余数法，稳定顺序补差，不能排出半台整机。末级需求保留原小数精度。能力用于初排后的预警，不自动平衡或移动超限量。

用户此次只更正能力口径，日期关系继续保持 scheduleDate = sourceDate − 7 个自然日，整机和备料均沿用当前日期模型。不得擅自把整机改为经营计划来源日。预警读最终排产日期能力；目标非生产日仍进入待分配，不自动移动。

## 6. 日排产及预警

新批次默认“整机产出”视图，展示整机料号、产出数量台、工厂及日期；另有“末级物料”视图供备料调整。周/月汇总提供相同口径选择，不能混合两类数量。

工厂当天负荷 = 本计划 active run 中 MACHINE_OUTPUT 当天 effectiveQuantity 合计。有效数量为人工覆盖值优先，否则系统值；实际完成量不代替计划量。所有整机型号共享本工厂当天能力。分页、料号筛选和视图切换均不改变完整工厂负荷。

| 条件 | 展示 |
|---|---|
| 已排 > 日产能 | 超产能，整机非零生产格及汇总标红 |
| 已排 = 日产能 | 满产，正常 |
| 停产且整机已排 > 0 | 停产日存在排产 |
| 日历缺失、能力无效或旧配置单位非台 | 产能未评估，提示维护配置 |

示例：整机A 600台 + 整机B 600台，日产能1,000台，负荷1,200台，超出200台。A的BOM每台需2个PCBA，PCBA自制计划即使变为1,200件，也不重复计入整机负荷。末级物料格不因整机超限而误标红。

## 7. 人工调整与版本

点击整机红格打开跨日调整：选择同一整机需求转移整数台数，展示两天整机能力、已排和调整后负荷，填写原因后一次保存转出/转入。允许空目标日期，拒绝停产/锁定/已执行目标，校验activeRun与两端revision。系统数量保留，来源月和需求总量守恒。

例如两天已排1,200/700台、能力各1,000台，转移200台后为1,000/900台，预警解除。调整末级物料只改变备料计划，不改变整机负荷；当前不自动联动备料跨日移动，用户按业务需要另行调整。

发布仍有能力异常时展示明细并要求当次确认，确认指纹绑定规则、快照、完整有效事实和负荷；任何计划变化使旧确认失效。发布生成独立只读事实，后续修改走修订，执行锁不可覆盖。

历史v2批次保留原末级能力口径及冻结快照，页面明确显示历史口径；不回填或把历史数值重新解释成整机台数。新批次/新修订用v3，冻结当前日历。修订保留已执行/锁定事实并遵守现有未来日期限制。

## 8. 验收案例

- 两工厂同一天能力独立；新配置/导入整数台，旧件配置明确提示重新维护。
- 整机库存扣减，BOM倍数、部件库存和供应方式变化均不会错误放大/消除整机负荷；根STOP不双算。
- 部件净需求0时仍有整机需求；根库存全覆盖时产出0。
- 整机整数日分配守恒，无半台；超限、满产、停产、未配置状态正确。
- 分页或末级物料视图不缩小工厂负荷，周/月不混合两种口径。
- 转移整数整机台数解除超限，末级调整不改整机负荷；空目标、锁、并发和发布确认失效正确。
- 日期仍提前7天，跨月使用最终日期能力；历史v2兼容，新v3真实计算及发布修订通过。
- 编译、单元测试、实际API/浏览器及独立复核全部通过后才标记完成。
