# MRP 业务规则库（Phase 2）

> 当前开发规则。旧 R001-R017 的周拆分规则属于 Phase 1 历史，详见 v3.0 和 00-09 阶段报告。

## 输入与版本

### P2-R001 经营计划

经营计划继续以整机料号+自然月为输入，每次确认导入生成不可变版本。

### P2-R002 输入冻结

计算绑定经营计划、库存、BOM、分类角色、物料策略、生产日历、业务决策和规则版本。任一输入变化使未发布批次 STALE。

### P2-R003 已出货 TODO

已出货本期不参与净需求、预检、checksum 和发布条件。数据字段可预留，但变化不得影响结果。

## 主数据和决策

### P2-R004 分类角色

业务维护 FINISHED_GOOD、HEAD_ASSEMBLY、PCBA、RAW_MATERIAL、OTHER、EXCLUDED、UNMAINTAINED。角色用于识别和展示，不单独决定下钻。

### P2-R005 物料策略

供应方式 SELF_MADE/PURCHASED/OUTSOURCED 与下钻策略 EXPLODE/STOP 独立维护，新写入必填且移除「未维护」选项。外购、委外不自动 STOP。2026-10-14 确认：缺策略不阻断，缺下钻策略默认继续至结构叶子；缺供应仍保留有效 STOP。完成后保存去重缺失清单及全部来源，历史结果不回填；内部供应缺失哨兵显示「未配置」。物料策略、库存策略新增均从有效物料管理表按编码/名称/规格分页搜索选择。

### P2-R006 不确定项前置

缺角色、缺库存、多有效 BOM、非生产日落点以及共享库存的人工覆盖等进入业务决策中心。系统按 `ANALYZING -> WAITING_DECISION -> REANALYZING` 波次推进；未人工覆盖的共享库存按来源月+经营计划顺序确定性分配。锁定全部稳定决策前不做最终计算，计算中不弹窗。

## 库存和净需求

### P2-R007 库存真源

原始导入数据确认后规范化到唯一计算库存真源。每份导入文件在快照范围头选择仓库，不在明细行重复映射工厂/库存组织。模板和原始行携带 `inventory_quality`：`GOOD` 参与 MRP，`DEFECTIVE` 只展示和追溯。按快照+仓库+物料+库存品质汇总，`inventory_item` 与 `inventory_detail` 不得相加。

### P2-R008 缺库存

有 0 记录是合法零库存；无记录生成 INVENTORY_MISSING。业务可修正/切换快照或仅对本批次确认 0。

### P2-R009 共享库存

同一仓库快照库存池跨来源整机、来源月份和 BOM 路径共享。库存不足时先按来源月，同月内按已冻结经营计划行顺序自动分配；人工调整必须填原因并留审计。

### P2-R009A 工厂仓库隔离

工厂与仓库使用已发布一对一映射。库存快照按仓库+物料+品质汇总，工厂只能扣减映射仓库库存，禁止跨永惠、爱培科、惠州仓合并扣减。

### P2-R009B 安全库存

按仓库+物料维护安全库存和预警库存。`allocatable=MAX(0,GOOD-safety)`，安全库存作为硬保底不得自动消耗；分配后低于预警/安全线生成风险提示，但继续计算需求缺口。

### P2-R010 逐层计算

```text
nodeNet = MAX(0, nodeGross - confirmedAllocation)
unitUsage = childQty / parentQty
childGross = parentNet * unitUsage
```

每层先扣本节点库存，只传播净需求。

### P2-R011 终止规则

STOP 使当前节点成为末级需求。EXPLODE 或缺失下钻策略有有效下级时继续；无下级的结构叶子成为末级需求。策略缺失生成排产结果清单，不进入阻断决策。

### P2-R012 BOM 异常

NC 同步按库存组织+父料号+子料号选择最高有效版本；MRP 只读取固化快照。循环、父项数量<=0、子项数量<=0、缺物料、重复最高版本、有效期重叠或库存组织不明均必须显式报错或决策，禁止静默跳过。根节点 EXCLUDED 需业务明确选择跳过或修正，中间节点 EXCLUDED 一律阻断。MVP 不做单位换算，按现有数字计算。

## 日排产

### P2-R013 日事实

日排产是唯一可编辑事实。周/月只按最终排产日期 SUM 日有效数量。

### P2-R014 来源日分配

新规则 `v3-whole-machine-capacity` 将整机根净需求（整数台）和月末级净需求分别按来源月份内有效生产日等权分配；历史批次使用原冻结权重。整数使用最大余数法，小数按物料精度，确保来源月守恒。

### P2-R014A 日产能（2026-10-14 用户确认）

C019更正：爱培科、永惠分别维护生产日、整机日产能台/日，正整数台。整机量来自根level0 netQty，独立MACHINE_OUTPUT日事实；最终日期仍来源日减7天。整批整机effectiveQuantity统计负荷，末级物料不参与；缺配置或旧非台能力明确未评估。超过能力时预警标红，跨日两端原子调整并守恒；分页筛选不改变负荷。能力和物料单位冻结到批次，新修订采用最新日历；发布异常需确认当前指纹。周产能配置退出当前入口，保留历史兼容。

### P2-R015 提前 7 天

最终排产日期=来源日期-7个自然日。跨月、跨年和五周月均按真实日期。

### P2-R016 非生产日

提前后的日期不是生产日时进入待分配池，由业务选择合法日期；系统不自动向前/向后移动。

### P2-R017 人工调整

系统值、人工值、最终值分开保存。同周重分配守恒；跨周必须原因和审计；未平衡时禁止发布。

## 页面和发布

### P2-R018 双料号列

排产主表固定展示“来源整机”和“末级需求物料”。末级可能是机头或 PCBA，禁止称“原材料料号”。

### P2-R019 日期语义

主表只展示最终排产日期，不展示来源需求周/实际排产周。来源月份/日期只在详情和守恒中使用。

### P2-R019A 业务周

业务按月发布 W1-Wn 的开始/结束日期，可跨自然月。周汇总和日表表头从该版本聚合日事实，不写死周一至周日，不生成可编辑周事实。

### P2-R020 发布门禁

阻断问题=0、待分配=0、日历合法、逐层守恒、日周月守恒、人工调整平衡、checksum 未变化才可发布。

### P2-R021 确定性

全链路 BigDecimal/DECIMAL(18,6)，稳定排序和稳定散列；同输入和决策输出一致。

### P2-R022 历史兼容

Phase 1 周计划表、旧 override 和旧 API 仅只读兼容；Phase 2 使用新增日表、日键和 API。已执行/已锁定日不可被重算覆盖；月中重算创建新 run；发布后修改生成修订批次，旧发布版本保留。
