# 阶段 18：集成、性能、安全与兼容

## 目标

执行全量后端/前端集成，验证性能、安全、权限、Phase 1 兼容和运维风险。

## 必读

`test-and-gates.md`、`security-and-ops.md`、`technology-baseline.md`、`change-control.md`、完整开发手册第 12/13 节。

## 执行

1. 按 `reports/stage18-19-five-hour-acceptance.md` 先核对代码/输入指纹和现有证据；同批修复收口后只跑一次全量后端/前端测试、定向 API 契约和关键浏览器链。
2. 使用当前上海 BOM、有效物料和完整库存的可复现大数据集验证 BOM、需求、日明细，无 N+1，批量 500-2000；旧混合组织夹具不得冒充当前性能基线。
3. 记录真实耗时、内存、CPU、SQL 数和响应大小，再决定性能阈值。
4. 验证所有权限码、工厂数据域、文件下载、审计和输入安全。
5. 移除 secret-like 默认值，要求环境变量并记录轮换；报告不得复述秘密。
6. 验证 Phase 1 历史 API/页面只读，Phase 2 不调用旧周 override。
7. 验证 GOOD/DEFECTIVE 库存导入、快照级聚合、BOM 版本冲突阻断、锁定日保护、执行差异异常和修订版本链路。
8. 修复所有 P0/P1 和本需求相关既有债务；其他债务写 issue-log。

## 门禁

- 本批一次全量三层验证通过，复用证据有未变输入/代码/断言的核对记录；
- 无高危安全、事务、并发、数据守恒或兼容缺陷；
- 性能报告有真实证据；
- 独立 Reviewer 从需求到代码/测试逐项审查。

完成后 REVIEW，PASS 后进入 19。
