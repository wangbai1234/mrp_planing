# MRP Excel 导入契约

## 1. 统一流程

```text
下载模板 -> 填写 -> 上传原始文件 -> staging 流式解析 -> 全表校验
-> 预览错误/识别结果 -> 用户确认 -> 正式版本 -> 可选触发排产重算
```

任何一行解析成功都不能直接写入正式版本。上传文件保存到 Docker 挂载卷，记录 SHA-256 checksum。

## 2. 经营计划

模板字段来自真实《经营计划表.xlsx》：业务线/工厂、形态、料号、名称、项目、平台、模具、状态、连续 6 个月 Forecast、fcst-total。

### 月份识别

- 读取表头单元格真实值，标准化为 `YYYY-MM`；
- 支持 Excel 日期、带日期格式的 numeric 和真实 Excel 日期序列值；
- 不能根据文件名、上传日期或“8月”文字猜年份；
- 校验 6 个月连续、无重复、无空值；
- 必须正确识别 `2026-12 -> 2027-01`；
- 预览显示识别出的完整年月和异常行。

Apache POI 使用 SAX/Event API；不得把超大工作簿完整加载到内存。

### 料号

料号必须按文本读取。发现科学计数法、日期、空白或被截断时，导入阻断并提示具体行列。

## 3. 库存快照

模板字段：`material_id, warehouse_code, warehouse_name, warehouse_type, factory_code, quantity, snapshot_date, is_in_calculation`。

校验：数量非负、快照日期真实有效、工厂不为空、仓库编码稳定、是否计入与不良品仓口径一致。永惠和 APK 分开汇总。

## 4. 产能配置

模板或页面字段：工厂、产线编码、产线名称、周产能、生效日期、启用状态、备注。

校验：工厂和产线编码必填；同工厂编码唯一；周产能为正整数；生效日期合法。保存后只重新标记超限，不自动搬移数量。

## 5. 错误和幂等

- 错误报告包含 sheet、行、列、原值、错误码和修复建议；
- 相同文件 checksum 在同一业务范围内不得重复生成正式版本，除非用户明确选择“重新导入”；
- 用户重复点击确认不能生成两个版本；使用数据库唯一键 + Redis 幂等键双重保护；
- 解析预览过期后必须重新校验，不能直接确认旧 staging 数据。
