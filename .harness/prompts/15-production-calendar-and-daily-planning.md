# 阶段 15：生产日历与日排产

## 目标

把末级月净需求分配到来源日，整体提前 7 个自然日，生成唯一日事实和只读周/月汇总。

## 必读

v4.0 第 7 节、`calculation-contract.md` 第 4-8 节、开发手册第 6.3 节。

## 执行

1. 按来源月份有效生产日权重分配月末级需求。
2. 整数使用最大余数法；小数按物料精度和稳定顺序补差。
3. `scheduleDate=sourceDate-7 days`；目标非生产日写待分配和 issue，不自动移动。
4. 业务确认合法日期后生成日事实。
5. 新增版本化业务周 W1-Wn 日期范围；周汇总按已发布范围 SUM 日 effective quantity，业务月汇总为所属 W1-Wn 之和，可另提供自然月只读口径。
6. 实现日 override、多日重分配、恢复自动、revision 和审计。
7. 增加业务手动确认已执行/已锁定日期和实际完成数量；锁定日期不可被重算或人工重分配覆盖，实际量不等于有效计划量时生成差异异常。
8. 月中重算只处理未来未锁定日期，每次生成新的 `mrp_calc_run`，不得覆盖旧 run；库存分配保留/重新分配未决时只生成预览，不得发布受影响结果。
9. 查询 12 周时覆盖截止日后 7 天来源需求。

## 门禁

- 28/29/30/31天、闰年、跨月/跨年、五周月；
- 节假日、调休、整周/整月停产；
- 非生产目标日阻断、整数/小数守恒；
- 日调整后周/月立即一致；
- MVP 只允许多日守恒重分配，不提供绕过守恒的单日写接口；
- 已执行/已锁定日期拒绝任何重分配请求；
- compile/test + MySQL 集成、服务启动/health 和日/周/月查询服务校验。完整 curl 结果 API 在阶段 16 验证。

完成后 REVIEW，PASS 后进入 16。
