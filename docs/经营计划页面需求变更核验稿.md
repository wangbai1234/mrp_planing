# 经营计划页面需求变更核验稿

版本：v1.0｜整理日期：2026-10-28｜状态：待产品经理核验

## 1. 背景与目标

经营计划是 MRP 的版本化输入，按工厂、整机料号、自然月维护。原先少量修改也需重新导入整份 Excel；把历史版本的所有料号逐行堆在主表又不便检索。因此本次目标是支持单行新增、编辑、删除、差异核验和审计追踪，同时使生效版与待发布调整清晰分离。

## 2. 核心业务规则

1. **生效版本**是供新建排产批次选择的完整正式经营计划。历史正式版不可原地修改。
2. **待发布调整**是基于生效版的唯一活动草稿。主表可预览，MRP 仍使用生效版。
3. **生成新版本**是核验草稿差异后形成新完整正式版、更新当前指针；旧版保持可追溯。
4. 数据唯一性按“工厂＋料号”，数量按自然月维护；月份结构来自当前生效版。
5. **业务状态**是 Excel 原有的可选料号属性，与版本的生效、历史、草稿状态不同，不参与排产数量计算。是否继续保留需产品确认。

## 3. 页面与入口

1. 页面默认仅展示生效版本的主表，不堆叠同料号历版记录。标题栏显示“生效版本 Vn”或“历史版本 Vn”；有草稿时显示“当前显示：待发布预览”、变更料号数，并提示尚未生效。
2. 主表一行对应工厂＋料号，展示工厂、形态、料号、名称、项目型号、规格型号、模具、业务状态、各月份数量、合计、操作。按料号／名称／工厂搜索，服务端分页，默认 20 行。
3. 顶部提供“查看版本”“版本差异”“新增”“导入”；活动草稿存在时提供“放弃变更”。“返回最新版本”只在历史版显示。顶部不设置“查看日志”。
4. 当前版行操作为“编辑”“删除”“查看日志”；历史版只读，可按权限查日志。行内不设“版本差异”，统一从右上角查询。
5. “版本详情”弹窗显示来源（导入／人工调整）、创建人和创建时间、生效人和生效时间。移除“业务制单人”的输入及展示，不在主表铺开审计小字。
6. 空数据、加载失败、无权限和接口异常均需明确提示，不得白屏或将失败误认为无数据。

## 4. 人工调整

### 4.1 新增

1. 仅在生效版新增单行；选择可用工厂和有效物料料号，填写形态、模具、可选业务状态、各月份数量和原因。业务上经营计划应选整机料号，但当前接口只校验物料有效性，是否限制物料分类见 P9。
2. 料号查询复用库存控制策略弹窗的远程模糊搜索：支持编码、名称、项目型号、规格型号；只返回有效物料，下拉每页 10 条。名称、项目型号及规格型号以物料主数据为准。
3. 自动带出当前版完整月份，初值为 0；前后端均禁止增减月份。没有正式版或可用月份时提示先导入。
4. 同一草稿内工厂＋料号唯一；重复新增应阻断；已标记删除的料号走恢复流程。
5. 保存后显示待发布预览，不改变生效版或当前排产输入。

### 4.2 编辑

1. 仅编辑当前版的单行。工厂、料号锁定；可修改现有月份数量及开放的形态、模具、业务状态，原因必填。更换工厂或料号须删除原行再新增。
2. 编辑只能改当前导入版本已有月份的单元格数值，不提供增加／减少月份控件；后端拒绝月份集合变化。
3. 数量为非负 DECIMAL(18,6)；保存进入待发布预览，不原地改写正式版。

### 4.3 删除、恢复、放弃

1. 删除当前版行须填写原因；先在草稿标记删除，预览隐藏该行，正式版不变。
2. 在“当前版与待发布调整”差异弹窗中选择删除项可填写原因恢复，恢复原工厂、料号和月份结构。
3. 第一次成功调整时自动创建草稿，其后复用；同一时间只有一份活动草稿。放弃草稿须填原因，确认后回到生效版。
4. 无实际差异时提示“无实际变更，放弃预览”。取消确认框只关闭弹窗，不能调用放弃接口，也不能报“放弃失败：未知错误”。
5. 所有写入携带草稿修订号；发现其他人已修改则提示冲突并刷新，不覆盖新数据。

## 5. 历史、差异、日志

1. “查看版本”弹窗按版本号搜索并分页；选择历史版后主表只读。“返回最新版本”回到生效版及其待发布预览。
2. 统一“版本差异”弹窗可比较两个正式版本，或比较生效版与草稿；按工厂＋料号＋月份核验，默认仅展示变化，支持料号／工厂关键词、显示未变化项及服务端分页。
3. 差异类型包含新增、删除、月份数量、属性变化；两个正式版比较还可识别优先级变化并展示新旧优先级。生效版与草稿的比较目前不识别优先级变化。展示工厂、料号、名称、月份、新旧数量、差额；摘要区分“变化料号数”和“变化月份行数”。
4. 属性差异范围包含名称、形态、项目型号、规格型号、模具、业务状态。当前弹窗仅显示“属性变化”分类，**未逐字段展示旧值和新值**，需产品决定是否补充。
5. 行内“查看日志”按工厂＋料号展示时间、操作人、动作、前后值和原因；新增、编辑、删除、恢复、创建／放弃草稿、发布、导入留痕。日志回答操作过程，差异回答版本间的数据变化。

## 6. 生成新版本与排产影响

1. 只有实际变更且草稿有有效料号、月份时才允许生成版本。发布前先展示服务端差异摘要和明细，填写原因并确认。无变化不得空发版本。
2. 发布原子生成完整正式版，更新当前版本指针并结束草稿；历史版不回写。
3. 确认时明确提示：与旧经营计划版本绑定的相关**未发布**排产批次将失效，需要重新生成；**已发布**排产不会自动重算。
4. 当前实现是将适用未发布批次标记 STALE；新建批次默认选择新生效经营计划。发布经营计划本身**不会自动执行完整异步排产**。各旧批次保留原版本绑定。

## 7. Excel 导入

1. 保留模板下载、上传预览、错误报告和确认导入；确认后生成一个新的完整正式版。
2. 有活动人工草稿时禁止确认导入，提示先发布或放弃，防止覆盖待发布调整。
3. 模板第一行表头、第二行提示、第三行起示例／数据。工厂、形态、料号必填；模具、业务状态选填；月份动态生成；数量合计由系统处理。
4. 工厂无效、料号无效、同工厂同料号重复等错误阻断确认，可下载错误报告；不能只导入成功部分。

## 8. 权限和数据约束

查看、导入、确认导入、新增、编辑、删除、生成版本、日志分别按现有权限控制，并验证工厂数据域。正式版本、草稿和日志分别保存系统操作元数据；“业务制单人”不作为新业务字段展示。历史迁移中的兼容字段不修改。列表、历史、差异、日志均用服务端分页。

## 9. 产品经理需裁决的问题

请对每项标记“接受现状／调整需求／暂缓”并备注：

| 编号 | 问题 | 当前情况 |
|---|---|---|
| P1 | 业务状态是否保留，取值和业务含义是什么？ | 原模板可选自由文本，当前可显示、编辑、做属性差异，不参与排产。删除需考虑历史数据与模板兼容。 |
| P2 | 属性差异是否要求在弹窗直接显示字段旧值和新值？ | 当前只显示“属性变化”分类，不能在差异列表逐字段核验。 |
| P3 | 是否允许人工调整优先级，入口应在何处？ | 优先级影响共享库存分配；当前人工编辑没有优先级输入，新增料号排在末尾。 |
| P4 | “排产重新生成”是用户手动发起还是系统自动触发？ | 当前将未发布旧批次标记失效并提示手动重新生成。 |
| P5 | 所有增删改、恢复、放弃、发布原因都必须填写吗？ | 当前全部必填。 |
| P6 | 是否继续全系统共用一份活动草稿？ | 当前只有一份，可能让多人／多工厂相互等待。 |
| P7 | 人工生成版本的列表状态、时间文案是否统一？ | 当前版本列表仍用“已导入”“导入时间”，版本详情可区分来源和生效时间。 |
| P8 | 查看历史版时是否显示“导入”按钮？ | 当前仍显示；点击后生成新的全局生效版，不会编辑所看的历史版。 |
| P9 | 新增查询是否必须限定为整机类别？ | 当前接口仅过滤有效物料，不按整机类别筛选；后端校验也只验证料号存在且有效。 |
| P10 | 仅变更业务状态等不参与排产的属性，是否仍使未发布排产批次失效？ | 当前任何真实差异发布后都会对绑定旧版本的适用未发布批次执行失效处理。 |

## 10. 产品验收清单

- [ ] 默认显示生效版、不堆历史行；只有看历史版才出现“返回最新版本”。
- [ ] 标题栏显示版本和待发布预览，版本详情能查人和时间，无业务制单人。
- [ ] 新增料号按编码、名称、项目型号或规格模糊分页查询，只允许有效物料。
- [ ] 新增和编辑不能增减月份；编辑不能改工厂、料号；服务端也拒绝越权提交。
- [ ] 保存、删除只影响草稿预览；恢复与放弃能正确回退；取消放弃不报错、不发请求。
- [ ] 差异从右上角统一查询，能核验跨版本的新增、删除、数量和属性变化；日志可追溯人、时间、原因及前后值。
- [ ] 生成前展示差异及排产影响；无变化不发布；新版本生效、旧版保留、草稿结束。
- [ ] 未发布旧批次失效，已发布批次不自动重算；新建排产默认选中新生效版。
- [ ] 活动草稿存在时阻断 Excel 确认导入；错误数据不能部分导入。
- [ ] 空态、加载、异常、权限和并发冲突均有明确反馈。

## 11. 核验依据与范围

本稿已对照当前经营计划页面、共用物料选择器、工作台服务与差异 SQL、导入服务、MRP 批次创建逻辑及既有浏览器验收报告。已有自测记录为后端 618 项、前端 100 项、隔离环境经营计划 Chromium 闭环通过。产品核验、独立复核和完整 MRP 异步重算仍未完成。
