# 代码与 SQL 约束

## Java

- Java 21；优先使用不可变 `record` 作为输入/输出值对象；
- 数量为 `long`，不得用 `int` 承载可能累计的生产量；
- 月份领域值使用 `YearMonth`，周使用 `LocalDate` 且校验周一；
- 所有事务边界放在 Application Service；Controller 不加复杂事务；
- 捕获异常必须保留 cause 和 traceId，禁止空 catch；
- 禁止静态全局可变状态；禁止使用系统当前时间散落计算，统一注入 `Clock`；
- 计算领域层不得依赖 Spring、数据库、HTTP、Redis；
- DTO、领域对象、持久化对象不得混用；
- 日志禁止包含密码、JWT、完整 Excel 内容和敏感配置。

## MyBatis / SQL

- SQL 只写 XML Mapper；参数使用 `#{}`，禁止 `${}` 拼接用户输入；
- 动态排序字段必须白名单映射；
- 批量查询和批量写入，禁止循环中访问数据库；
- 新查询在任务报告中给出索引使用说明；大查询使用 `EXPLAIN`；
- 所有列表稳定排序，分页条件包含唯一键；
- 禁止 `SELECT *` 用于正式 Mapper；
- 版本结果表禁止 UPDATE 数量；新计算写新版本。

## Vue / TypeScript

- `strict` TypeScript；禁止滥用 `any`；
- API 类型集中定义，错误与任务状态有判别联合类型；
- 组件按业务特性拆分，单组件不得同时承担数据访问、规则计算和全部展示；
- 正式业务公式不在前端计算；
- 按钮有文字，图标为统一 SVG；状态不能只靠颜色；
- 表格支持键盘焦点、加载、空数据、失败和重试状态；
- 页面卸载时停止轮询，轮询有退避和超时。

## 测试

- 测试名描述业务行为和期望结果；
- 黄金数据写明来源规则；
- 禁止用脆弱的页面文本字符串代替核心算法断言；
- 数据库测试必须清理自己的数据，不依赖测试执行顺序。
