# MRP Phase 2 第八轮真实运行验收与剩余业务数据阻断报告

## 一、验收结论

验收日期：2026-09-29。

本轮已完成代码复核、数据库迁移、后端全量测试、前端构建与单元测试、真实 API 联调以及 Google Chrome 重点页面验收。已确认配置页面不再跳登录、权限配置可见、库存品质中文化、批次问题接口无冲突、旧批次有安全门禁。

当前项目仍不满足“完整业务 UAT 已通过”的完成定义。阻断原因不是 Docker，也不是服务无法启动，而是当前数据库中的工厂编码体系不一致，且工厂仓库映射、库存控制策略、业务周和新版库存快照尚未按真实业务准备。

## 二、本轮代码修复

新增 Flyway V034，仅修复数据库中已经确认的 UAT 双重编码值，不批量转换其他历史原因，避免误伤合法中文。

### 2.3 页面与权限

- 物料策略、生产日历页面可正常访问和打开新增入口，不再返回登录页。
- `/roles/1/permissions` 已包含 Phase 2 新页面和业务周权限。
- 库存导入弹窗支持仓库和品质，列表显示“品质”，值为“良品/不良品”。
- MRP 工作台采用单一当前排产入口，历史批次用于只读查看。

## 四、真实数据阻断

### 4.1 工厂编码体系

- 产能配置：永惠、爱培科；
- 经营计划：F001、F002；
- 已发布生产日历：F001。

需要业务确定统一工厂编码。若“永惠、爱培科”实际是工厂名称，应明确对应的工厂编码；若是仓库或组织名称，则应迁移到正确字段。

### 4.2 工厂仓库映射

当前没有已发布映射。业务需明确工厂与永惠仓、爱培科仓、惠州仓的一对一关系。系统将按批次锁定该版本，计算时只扣对应仓库，禁止跨仓混用。

### 4.3 库存快照

现有快照仓库字段为空，属于旧数据，不能作为新版正式批次输入。应使用最新模板重新导入，至少包含仓库、物料类别、物料料号、品质、库存数量；良品参与计算，不良品保留追溯但不参与可用量。

### 4.4 库存控制与业务周

当前没有已发布库存控制策略和业务周版本。需要维护安全库存、预警库存，以及各自然月 W1-Wn 的日期范围。日排产以日期为唯一事实，周仅用于统计汇总。

## 五、完整 UAT 操作顺序

1. 统一工厂编码，修正产能、经营计划和生产日历主数据。
2. 发布工厂仓库映射。
3. 发布库存控制策略。
4. 发布目标月份业务周。
5. 检查分类角色和物料策略已发布。
6. 从 NC 同步并固化唯一有效 BOM 快照。
7. 使用新版模板导入库存快照。
8. 创建当前排产批次。
9. 运行预检并由业务处理缺库存、角色、供应方式等决策问题。
10. 开始计算，核对共享库存按经营计划顺序分配、安全库存保底和预警提示。
11. 在日排产网格核对整机料号、末级需求物料和逐日数量。
12. 在周/月汇总核对业务 W1-Wn 和月度守恒。
13. 处理待分配数量，确认执行状态，完成发布。
14. 月中重算时明确选择“保留原分配”或“重新分配”，验证锁定/已执行日不被覆盖。
15. 发布后如需修改，创建修订版本，不覆盖历史结果。

## 六、下一轮完成标准

只有在真实业务主数据准备完成后，完整流程成功运行，并核对库存守恒、需求守恒、日/月守恒、仓库隔离、安全库存和历史不可变，才可将 Phase 2 最终状态改为完成。
