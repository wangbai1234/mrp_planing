# Prompt 06：实现 Vue 前端和排产工作台

前置：API 契约稳定且有可调用测试环境。

创建 `frontend/`：Vue 3 + TypeScript + Vite + Element Plus。只按已确认 Phase 1 页面实现：工作台、滚动排产、经营计划、库存快照、版本记录、产能配置、操作手册。

排产页必须：

- 固定物料列 + 连续 12 周横向网格；
- 周一至周日、物理月份、来源月份、提前量、当前周、锁定、人工调整、超产能文字同时可见；
- 横向滚动查看，不提供“滚动一周”；
- “定位当前周”只回到当前视图起点；
- 点击单元格打开详情抽屉，显示公式、自动值、人工值、最终值、修改历史；
- 进度轮询重算任务；
- 两个自动重算开关只放在排产页；
- 经营计划和库存按模板下载→上传→预览→确认；
- 产能支持新增、整行编辑、保存、取消；
- 图标统一 SVG，禁止 emoji。

前端不得复制正式业务公式；只做展示、输入和交互状态。使用真实料号和模板字段。运行 lint、build，并用浏览器完成核心验收。完成后状态设为 REVIEW，等待复核。
